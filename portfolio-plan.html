정재은 포트폴리오
기획서

01 · BACKGROUND
기획 배경

브랜딩, 모바일 UI 등 그동안 해온 디자인 작업이 여러 곳에 흩어져 있어, 한눈에 보여줄 수 있는 공간이 없었습니다. 인트로부터 프로필·작업물·문의까지 섹션별로 이어지는 구성으로 작업을 소개하고, 앞으로의 작업도 계속 채워나갈 수 있는 나만의 포트폴리오 사이트를 만들고 싶습니다.

02 · AUDIENCE
누가 보나요

보는 사람

디자이너를 찾는 채용 담당자, 브랜딩·UI 작업을 맡기고 싶은 클라이언트, 함께 작업할 동료

보여주고 싶은 것

브랜딩과 모바일 UI 작업물, 그리고 디테일까지 설계하는 디자이너라는 인상
확인 필요 — 인트로 시안의 UI/UX · WEB · AI VISUAL · 3D를 실제 전문 분야로 표기할지 확정한 뒤 이 문구와 통일

04 · FEATURES
핵심 기능
인트로 · 제목 전환
화면을 채우는 인트로(좌측 하단 Portfolio, 우측 상단 소개 문구)와 첫 진입 애니메이션. Who am I · Works · Contact 제목이 크게 나타난 뒤 스크롤에 따라 작아져 고정 — 움직임 최소화 설정에서는 정적으로 표시
필수
자기소개
좌측 프로필 이미지, 우측 경력(Experience)·학력(Education)
필수
툴 · 스킬
단색 도구 로고와 5단계 숙련도 그래프(‘4/5’ 같은 텍스트 병기), 각 도구로 실제 수행할 수 있는 업무 설명
필수
작업물 목록
메인에 대표작 최대 4개를 우측에 세로로 나열, 4개를 넘으면 ‘프로젝트 더 보기’로 전체 작업물 페이지 이동
필수
문의하기
기업명 · 성함 · 이메일 · 문의 내용을 남겨 문의와 채용 제안을 받는 폼
필수
작업물 상세
작업물을 누르면 작업 과정과 결과를 자세히 보여주기 — 기능정의서와 통일해 첫 공개에 포함
필수

확정 전 확인할 것

  • UI/UX · WEB · AI VISUAL · 3D를 실제 전문 분야로 쓸지
  • PC에서도 메뉴를 아이콘으로 펼칠지, 상단 메뉴를 유지할지
  • Contact 제목도 섹션 끝까지 고정할지
  • 인트로 효과의 길이와 재방문 시 재생 여부
  • 푸터 이미지와 ‘카피라이터’ 문구(카피 문구인지 저작권 표기인지)
  • 메인 작업물 이미지 비율

Contact

이미지 푸터
큰 이미지 배경 위에 카피 문구 — 글자가 잘 읽히도록 오버레이 또는 별도 텍스트 영역 사용
모바일은 별도 페이지가 아니라 각 화면의 반응형 상태로 설계합니다. 긴 프로필 · 작업물 · 문의 영역은 모바일에서 고정을 완화해 내용이 가려지지 않게 합니다.
06 · GOAL
얻고 싶은 것

GOAL
